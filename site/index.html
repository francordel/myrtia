Capabilities

Not a single attacker. A council.

Where library and CLI tools such as IBM ARES and NVIDIA garak are the reference for LLM red teaming, Myrtia is built around autonomous multi-agent attackers, with a real front-end and analytics.

C

Live CouncilAttack

N models propose, cross-critique, vote (Borda), a chairman synthesises, and an in-loop judge grades — streamed live, turn by turn.

A

Multiple attacks

Council, crescendo (multi-turn escalation) and a direct baseline, each with its own configurable schema.

B

Behaviour library

278 HarmBench behaviours across five themes, selectable by theme and search — or your own goals.

P

Any provider

OpenAI, Anthropic, self-hosted vLLM and local Ollama, mixed freely across council, chairman, judge and target.

S

ASR analytics

Attack Success Rate by attack, target and theme; score distributions; per-council-member vote win-rates.

H

Searchable history

Every run is persisted, searchable and filterable, and replays its full deliberation on demand.

Why Myrtia

The realistic threat model, made observable.

Safety-aligned frontier models refuse to author jailbreaks, so Myrtia pairs a permissive open-model council with the frontier target under test — and shows every step.

Quick start

Running in three commands.

# install
cd backend && pip install -e . && pip install -e vendor/ares-council

# run the server (API + web UI)
uvicorn myrtia.api.app:app --port 8000

# open the console
open http://127.0.0.1:8000/
