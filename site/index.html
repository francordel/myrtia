Six strategies, one contract.

Attacks are plugins with an ARES-compatible contract. Council attacks carry an in-loop judge; the baselines record the raw response.

AttackWhat it doesScoring
councilN attacker models propose, cross-critique and vote (Borda Top-1); a chairman synthesises the winner and strikes the target. Each turn is a fresh prompt.in-loop judge 0-5
council-crescendoThe same pipeline, but the target conversation accumulates across turns: gradual escalation.in-loop judge 0-5
directSends each behaviour verbatim. The baseline every other attack is compared against.raw response
human-jailbreakWraps each behaviour in known persona templates (DAN, AIM, dev-mode and others).raw response
obfuscationEncodes the behaviour (base64, ROT13, leetspeak, reversed) and asks the target to decode and comply.raw response
payload-splittingSplits the behaviour into innocuous fragments the target is asked to reassemble.raw response

Build your own agentic attack

  • Council models. Any mix of local and hosted models as attacking agents.
  • Council system prompt. The attacker persona shared by the agents.
  • Critique style. Hardened or soft cross-critique.
  • Chairman and judge. Separate models for synthesis and grading.
  • Turns and voting. Turn budget, Borda and chairman on or off.

The realistic threat model

  • Frontier models refuse to author jailbreaks, so they make poor attackers.
  • Myrtia pairs a permissive open-model council with the frontier target under test.
  • A capable judge is load-bearing: a weak judge inflates ASR.

Built to run on your own machine.

A local, single-operator tool that is careful with your keys and with what the backend can reach.

Keys stay in the browserSupplied at run time, stored locally, redacted from every response and event.
SSRF guardLink-local and cloud-metadata addresses are refused; loopback and LAN stay available.
Local-only CORS and CSPThe API answers local origins only, with CSP, frame denial and nosniff.
Durable historyRuns and statistics persist in a local SQLite database with owner-only permissions.
Stop any runCooperative cancellation at the next turn, from the run header.
Escaped everywhereAPI text is escaped before rendering; external links must be http(s).

Running in three commands.

Python 3.11+. A local Ollama with a small model is enough to see a council deliberate, no API key needed.

# install
cd backend && pip install -e . && pip install -e vendor/ares-council

# run the server (API + console)
uvicorn myrtia.api.app:app --port 8000

# open the console
open http://127.0.0.1:8000/
